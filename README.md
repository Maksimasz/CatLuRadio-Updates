# CatLu Radio

CatLu Radio — настольный плеер интернет-радио для Windows. Он помогает находить станции, слушать их в одном окне и сохранять любимые.

## Возможности

- Поиск станций по названию, жанру и стране.
- Отдельный выбор каталога в поиске — понятно, откуда найдена станция.
- Избранные станции и история прослушивания.
- Прослушивание перед добавлением в избранное.
- Эквалайзер и регулировка громкости.
- Резервные потоки для станций, если основной недоступен.

## Установка и обновление

Откройте последний выпуск в разделе **Releases**, скачайте установщик и запустите его. Новая версия устанавливается поверх старой и сохраняет ваши станции и настройки.
